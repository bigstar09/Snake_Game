# Snake Battle

강화학습으로 배운 AI와 60초 동안 사과 먹기 대결!

**게임 실행: https://bigstar09.github.io/Snake_Game/**

## 플레이 방법

1. 닉네임과 난이도를 선택하고 시작하세요.
2. 방향키로 움직여 사과를 먹으세요. 사과를 먹으면 몸이 길어집니다.
3. 벽이나 자신의 몸에 부딪히면 3초 후 다시 움직일 수 있습니다.
4. 60초 동안 사과를 더 많이 먹으면 승리합니다.

ESC: 일시정지. 입력이 되지 않으면 게임 화면을 먼저 클릭하세요.

## 웹 버전

- 로비, 대결·결과, AI 성장 보기를 포함합니다.
- 난이도마다 20만·40만·160만 스텝 학습 모델을 사용합니다.
- Training 씬과 Python 학습기는 포함하지 않습니다.
- 랭킹은 해당 기기의 브라우저에 저장됩니다. 다른 기기와 공유되지 않습니다.
- Chrome과 WebGL 2를 지원하는 환경에서 실행하세요.

이 저장소에는 Unity 프로젝트의 웹 빌드 결과물이 들어 있습니다.
`index.html`을 파일로 직접 열지 말고 위 게임 주소 또는 HTTP 서버를 이용하세요.

폰트: 카페24 써라운드·써라운드 에어. 이용 조건은 `Licenses/`를 확인하세요.

## 알려진 사항

ML-Agents 4.1.0의 임시 데이터 정리 과정(`TensorProxy.Finalize → Dispose`)에서 빈 데이터를 참조하는 예외가 브라우저 개발자 콘솔에 표시될 수 있습니다. 현재 검증한 경기 진행과 AI 플레이는 동작합니다. 이 패키지 예외가 남은 시연용 빌드입니다.
